# Swiggy Sales Dashboard

## Project Overview
This project showcases an interactive Swiggy Sales Dashboard built using Advanced Excel.  
The dashboard provides insights into sales performance, customer ratings, food category trends, order analysis, and regional sales distribution.

---

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization

---

## Dashboard Features
- Total Sales Analysis
- Average Rating Monitoring
- Average Order Value Analysis
- Monthly Sales Trend
- Daily & Weekly Sales Analysis
- Food Category-wise Sales
- State-wise Sales Visualization
- Top Performing Cities
- Restaurant-wise Filtering

---

## Key Insights
- Total sales reached ₹53.0M.
- Average customer rating remained stable at 4.34.
- Non-Veg category generated the highest sales contribution.
- Bengaluru recorded the highest city-wise sales.
- Weekend sales were slightly higher compared to weekdays.
